# **Risk Prevention Setup**

## **Overview**  
This project uses **AdsPower Browser** and **922 Proxy** to prevent risks such as account bans by randomizing browser fingerprints and ensuring anonymous connections.  

---

## **Tools Used**

1. **[AdsPower Browser](https://www.adspower.com/download)**  
   - Automatically randomizes browser fingerprints for each profile.  

2. **[922 Proxy](https://www.922proxy.com/download)**  
   - Provides rotating IPs for secure and anonymous browsing.  

---

## **Setup**

1. **Download AdsPower Browser** from [here](https://www.adspower.com/download).  
2. **Sign up for 922 Proxy** at [this link](https://www.922proxy.com/download).  
3. Configure AdsPower Browser with 922 Proxy details to ensure unique profiles and anonymous connections.
